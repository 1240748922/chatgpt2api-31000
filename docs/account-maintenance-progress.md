# 后台账号同步进度与可用性面板（3.2.37）

## 后台会做什么

- 现有生命周期维护在维护实例（默认 app0）分批执行：待核验凭据、AT 续期、未知额度同步、限额账号复查。仍按性能信号决定正常、小批试探、减速或暂停，不同时请求整个账号池。
- “可尝试恢复”表示有可供尝试的凭据，不保证 RT 有效、额度已恢复或槽位空闲。确认 RT 失效后退出自动续期候选；临时故障、退避和共享凭据租约保护保持原样。
- AT 过期本身不会删除账号，RT 续期失败也不在续期这一步删除账号。有效 AT 不因 RT 无效而丢弃；两者均不可用时可以补凭据或在账号管理预览后手动清理。
- 独立的“确认异常账号”处理仍遵循原 `auto_remove_invalid_accounts` 配置。面板显示该配置的实际值，不修改开关、不执行删除。临时超时不等于确认异常。

## 计数口径

概览提供候选账号、已知就绪额度、实际正在处理数和本进程累计处理次数。详情分三个页签：同步进度、凭据与额度、处理规则。

- **正在处理**：生命周期维护的 AT 续期/额度同步 worker 已开始且未结束的数量，包含 worker 内部的网络/锁/槽位等待，不等于瞬时 HTTP 连接数。
- **每批最多**：当前性能调度许可的批大小，不是正在处理数。
- **当前批次**：当前维护调用已完成/总目标数及尚未开始的数。等待预检/提交/收尾时，批次尚在但实际 worker 数可能为 0。
- **累计成功/失败/跳过**：维护实例本进程启动以来的处理次数，同一账号可多次计数。预检失败合入批次计数；中断前未处理的目标不冒充成功或失败。失败可能是临时故障，不等于需要删除。
- **统计范围**仅为后台 AT 续期与额度同步；不包含手动操作、导入任务和鉴权核验。不是所有后台线程或整个集群的账号操作数。
- 重启后累计归零。没有维护采样、请求到非维护实例时显示 `--`，不会误显示为 0。采样过期会提示，错误时保留最近采样但不冒充实时结果。

## 性能与兼容

- `GET /api/accounts/maintenance-status` 需要管理员认证，只读取有界内存计数和维护策略，不扫描账号池、不操作数据库或调用上游、不返回邮箱/AT/RT/原始错误。
- 详情打开且页面可见时约 3 秒采样一次；关闭/卸载后不继续请求。全量可用性摘要仍约 15 秒一次，没有增加大池扫描频率。
- 记录器只保留当前批次、最近一批和累计数字，不存储无限任务历史。短内存锁不跨网络或数据库调用。手动同步/导入不受维护计数器控制。
- 不改生图准入、RT 轮换、共享租约、自动删除规则、性能阈值、导号加速、生图/超分并发、预热或代理配置；不改真实 `.env`、`config.json` 和数据库结构。
- 前端沿用唯一 Vue runtime。其他构建模块的修改仅为统一缓存版本，避免旧入口混载多个 Vue 导致导航/弹窗失效。

```powershell

python -X utf8 -m pytest src_extract/tests/test_account_maintenance_progress.py src_extract/tests/test_account_availability_browser.py -q
node src_extract/tests/test_account_availability_web.cjs
```

覆盖真实 service executor 的并发起止、失败/跳过、手动操作隔离、管理员认证、不扫描池，以及真实构建页面的导航、导入、实时刷新、关闭/Esc、页签键盘、390/768/1440 宽度、深色和大数字防溢出。浏览器截图输出到 `.runtime/availability-v2-*.png`；这些图片使用合成统计，不是生产账号数据。

## 更新后检查

1. `/version` 为 `3.2.37`。概览/账号管理能显示账号可用性，未采样的数字应为 `--`。
2. 有待处理账号且调度允许时，打开同步进度，观察正在处理数及累计次数变化；短任务可能在两个采样间完成，正在处理为 0 但累计增加是正常情况。
3. 暂停时检查性能调度原因；本更新只增加可观测性和整理样式，不会强行提高后台并发或恢复已失效 RT。
4. “处理规则”显示现有自动移除配置；不要将“累计失败”当成应批量删除的账号数。
5. 上一版回退镜像为 `sha-3c1535b`（3.2.36）。升级/回退均先排空在途任务，不清凭据租约、不删卷。
